# Junior Programmer Pathway
My course files for the Junior Programmer Pathway offered through Unity.  
https://learn.unity.com/pathway/junior-programmer

## Units
1. Player Control
2. Basic Gameplay
3. Sound and Effects
4. Gameplay Mechanics
5. User Interface
6. Publishing Your Project
7. Manage Scene Flow and Data
8. Apply Object-Oriented Principles

## About the Pathway
You will learn to Create with Code as you program your own exciting projects from scratch in C#. As you iterate with prototypes, tackle programming challenges, complete quizzes, and develop your own personal project, you will transform to a capable Unity developer.
